# Animal_Detection_System_on_Railway_Track
Developed an Animal Detection on Railway Track system using YOLOv8 to detect animals on or near railway tracks in real time and help prevent accidents. The system processes live camera/video input, identifies animals such as elephants and tigers, and triggers instant alerts for quick action. Built a Flask-based web interface for live monitoring with detection results, alert messages, and an alarm system. Integrated Slack alerts to notify the control room when an animal is detected. This project helps improve railway safety by supporting faster detection, early warning, and timely response.
